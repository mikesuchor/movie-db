# Movie Database

Browse trending movies, watch trailers, and hide the ones you've already seen. Built with React and the [TMDB API](https://www.themoviedb.org/), using LocalStorage for favorites and hidden movies.

Live site: https://movie-database.netlify.app/

## Scripts

Requires Node 20.19+ (see `.nvmrc`).

- `npm install` installs dependencies.
- `npm run dev` (or `npm start`) runs the app at http://localhost:5173 with hot reloading.
- `npm run build` builds the production site into `build/`.
- `npm run preview` serves that build locally.

Built with [Vite](https://vite.dev/). Netlify deploys use `netlify.toml`.
